# Лабораторная работа 2 - Параллельный парсинг веб-страниц

## Обзор
Данная лабораторная работа посвящена изучению различных подходов к параллельному парсингу веб-страниц с использованием Python. Реализованы три различных подхода: многопоточность, мультипроцессинг и асинхронное программирование.

## Структура Проекта
```
Lr2/
├── parsers/
│   ├── threading_parser.py    # Многопоточный парсер
│   ├── multiprocessing_parser.py  # Мультипроцессорный парсер
│   ├── async_parser.py       # Асинхронный парсер
│   ├── config.py            # Конфигурация парсеров
│   ├── db_models.py         # Модели базы данных
│   ├── summary.py           # Логирование результатов
│   └── main.py              # Основной скрипт
└── requirements.txt         # Зависимости проекта
```

## Описание Парсеров

### Многопоточный Парсер (ThreadingParser)
Использует модуль `threading` для параллельного выполнения задач. Особенности:
- Создает пул потоков для параллельного парсинга
- Использует блокировки для синхронизации доступа к общим ресурсам
- Эффективен для I/O-bound операций
- Хранит результаты в общей памяти

### Мультипроцессорный Парсер (MultiprocessingParser)
Использует модуль `multiprocessing` для параллельного выполнения задач. Особенности:
- Создает отдельные процессы для парсинга
- Использует очереди для межпроцессного взаимодействия
- Эффективен для CPU-bound операций
- Избегает проблем с GIL (Global Interpreter Lock)

### Асинхронный Парсер (AsyncParser)
Использует модуль `asyncio` для асинхронного выполнения задач. Особенности:
- Использует корутины для неблокирующего выполнения
- Эффективен для I/O-bound операций
- Позволяет обрабатывать множество соединений одновременно
- Использует SSL-контекст для безопасных соединений

## Сравнение Производительности

### Результаты Тестирования
| Парсер | Время выполнения (сек) | Количество задач | Ошибки |
|--------|----------------------|------------------|--------|
| Threading | 1.85 | 50 | 0 |
| Multiprocessing | 1.72 | 50 | 0 |
| Async | 1.66 | 50 | 0 |

### Анализ Результатов
1. **Асинхронный подход** показал наилучшую производительность благодаря:
   - Эффективному использованию системных ресурсов
   - Отсутствию накладных расходов на создание потоков/процессов
   - Оптимизированной работе с сетевыми запросами

2. **Мультипроцессорный подход** показал хорошие результаты:
   - Параллельное выполнение на разных ядрах процессора
   - Отсутствие проблем с GIL
   - Надежная изоляция процессов

3. **Многопоточный подход** показал немного худшие результаты:
   - Ограничения GIL
   - Накладные расходы на управление потоками
   - Потенциальные проблемы с синхронизацией

## Начало Работы

### Установка
1. Клонировать репозиторий
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настроить GitHub токен (опционально):
   ```bash
   export GITHUB_TOKEN=your_token_here
   ```
4. Запустить парсеры:
   ```bash
   python -m parsers.main
   ```

### Настройка
- Изменить количество задач для парсинга в `config.py`:
  ```python
  MAX_TASKS_PER_REPO = 10  # Количество задач на репозиторий
  ```
- Настроить список репозиториев:
  ```python
  REPOSITORIES = [
      "python/cpython",
      "django/django",
      "pallets/flask"
  ]
  ```

## Заключение
Лабораторная работа демонстрирует различные подходы к параллельному программированию в Python. Каждый подход имеет свои преимущества и области применения:
- Асинхронное программирование - для I/O-bound задач
- Мультипроцессинг - для CPU-bound задач
- Многопоточность - для задач с частым I/O и простой синхронизацией
