# Лабораторная работа 1 - REST API для системы управления задачами

## Обзор
Данная документация описывает реализацию Лабораторной Работы 1, которая фокусируется на создании REST API для системы управления задачами.

## Структура Проекта
```
Lr1/
├── lab/
│   ├── db/           # Модели и конфигурации базы данных
│   ├── rest/         # Реализация REST API
│   │   ├── task/     # Эндпоинты для задач
│   │   ├── sprint/   # Эндпоинты для спринтов
│   │   ├── project/  # Эндпоинты для проектов
│   │   ├── user/     # Эндпоинты для пользователей
│   │   ├── comment/  # Эндпоинты для комментариев
│   │   └── task_link/# Функциональность связывания задач
│   └── migrations/   # Миграции базы данных
└── prac/            # Практические задания
```

## Модели Базы Данных

### Модель Проекта (Project)
Модель Project представляет проект в системе со следующими атрибутами:
- ID (Первичный ключ)
- Название
- Описание
- Дата создания
- Дата обновления

### Модель Пользователя (User)
Модель User представляет пользователя системы со следующими атрибутами:
- ID (Первичный ключ)
- Имя пользователя
- Email
- Хеш пароля
- Дата создания
- Дата обновления

### Модель Задачи (Task)
Модель Task представляет рабочий элемент в системе со следующими атрибутами:
- ID (Первичный ключ)
- Название
- Описание
- Статус
- Дата создания
- Дата обновления
- ID проекта (Внешний ключ)
- ID пользователя (Внешний ключ)

### Модель Спринта (Sprint)
Модель Sprint представляет ограниченный по времени итерационный период со следующими атрибутами:
- ID (Первичный ключ)
- Название
- Дата начала
- Дата окончания
- Статус
- ID проекта (Внешний ключ)

### Модель Комментария (Comment)
Модель Comment представляет комментарий к задаче со следующими атрибутами:
- ID (Первичный ключ)
- Текст комментария
- Дата создания
- ID задачи (Внешний ключ)
- ID пользователя (Внешний ключ)

### Модель Связи Задач (TaskLink)
Модель TaskLink управляет отношениями между задачами:
- ID (Первичный ключ)
- ID исходной задачи (Внешний ключ)
- ID целевой задачи (Внешний ключ)
- Тип связи

## REST API Эндпоинты

### Проекты
- `GET /api/projects` - Получить список всех проектов
- `POST /api/projects` - Создать новый проект
- `GET /api/projects/{id}` - Получить детали проекта
- `PUT /api/projects/{id}` - Обновить проект
- `DELETE /api/projects/{id}` - Удалить проект

### Пользователи
- `GET /api/users` - Получить список всех пользователей
- `POST /api/users` - Создать нового пользователя
- `GET /api/users/{id}` - Получить детали пользователя
- `PUT /api/users/{id}` - Обновить пользователя
- `DELETE /api/users/{id}` - Удалить пользователя

### Задачи
- `GET /api/tasks` - Получить список всех задач
- `POST /api/tasks` - Создать новую задачу
- `GET /api/tasks/{id}` - Получить детали задачи
- `PUT /api/tasks/{id}` - Обновить задачу
- `DELETE /api/tasks/{id}` - Удалить задачу

### Спринты
- `GET /api/sprints` - Получить список всех спринтов
- `POST /api/sprints` - Создать новый спринт
- `GET /api/sprints/{id}` - Получить детали спринта
- `PUT /api/sprints/{id}` - Обновить спринт
- `DELETE /api/sprints/{id}` - Удалить спринт

### Комментарии
- `GET /api/comments` - Получить список всех комментариев
- `POST /api/comments` - Создать новый комментарий
- `GET /api/comments/{id}` - Получить детали комментария
- `PUT /api/comments/{id}` - Обновить комментарий
- `DELETE /api/comments/{id}` - Удалить комментарий

### Связи Задач
- `GET /api/task-links` - Получить список всех связей задач
- `POST /api/task-links` - Создать новую связь задач
- `DELETE /api/task-links/{id}` - Удалить связь задач

## Детали Реализации

### Конфигурация Базы Данных
Проект использует SQLAlchemy в качестве ORM с PostgreSQL в качестве бэкенда базы данных. Конфигурация базы данных управляется через переменные окружения в файле `.env`.

### Реализация API
REST API реализован с использованием фреймворка FastAPI, который предоставляет:
- Автоматическую документацию OpenAPI
- Валидацию запросов/ответов
- Поддержку асинхронности
- Подсказки типов

### Функции Управления Системой
1. Управление Проектами
   - Создание и управление проектами
   - Назначение пользователей на проекты
   - Отслеживание прогресса проекта

2. Управление Пользователями
   - Регистрация и аутентификация пользователей
   - Управление правами доступа
   - Профили пользователей

3. Управление Задачами
   - Создание и управление задачами
   - Назначение задач пользователям
   - Отслеживание статуса задач

4. Управление Спринтами
   - Создание и управление спринтами
   - Связывание задач со спринтами
   - Отслеживание прогресса спринта

5. Управление Комментариями
   - Добавление комментариев к задачам
   - Редактирование комментариев
   - Удаление комментариев

6. Зависимости Задач
   - Связывание задач для отображения зависимостей
   - Управление отношениями между задачами
   - Отслеживание зависимостей задач
