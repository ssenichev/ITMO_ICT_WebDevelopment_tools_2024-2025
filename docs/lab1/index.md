# Лабораторная работа 1 - REST API для системы управления задачами

## Обзор
Данная документация описывает реализацию Лабораторной Работы 1, которая фокусируется на создании REST API для системы управления задачами.

## Структура Проекта
```
Lr1/
├── lab/
│   ├── db/           # Модели и конфигурации базы данных
│   ├── rest/         # Реализация REST API
│   │   ├── task/     # Эндпоинты для задач
│   │   ├── sprint/   # Эндпоинты для спринтов
│   │   └── task_link/# Функциональность связывания задач
│   └── migrations/   # Миграции базы данных
└── prac/            # Практические задания
```

## Модели Базы Данных

### Модель Задачи (Task)
Модель Task представляет рабочий элемент в системе со следующими атрибутами:
- ID (Первичный ключ)
- Название
- Описание
- Статус
- Дата создания
- Дата обновления

### Модель Спринта (Sprint)
Модель Sprint представляет ограниченный по времени итерационный период со следующими атрибутами:
- ID (Первичный ключ)
- Название
- Дата начала
- Дата окончания
- Статус

### Модель Связи Задач (TaskLink)
Модель TaskLink управляет отношениями между задачами:
- ID (Первичный ключ)
- ID исходной задачи (Внешний ключ)
- ID целевой задачи (Внешний ключ)
- Тип связи

## REST API Эндпоинты

### Задачи
- `GET /api/tasks` - Получить список всех задач
- `POST /api/tasks` - Создать новую задачу
- `GET /api/tasks/{id}` - Получить детали задачи
- `PUT /api/tasks/{id}` - Обновить задачу
- `DELETE /api/tasks/{id}` - Удалить задачу

### Спринты
- `GET /api/sprints` - Получить список всех спринтов
- `POST /api/sprints` - Создать новый спринт
- `GET /api/sprints/{id}` - Получить детали спринта
- `PUT /api/sprints/{id}` - Обновить спринт
- `DELETE /api/sprints/{id}` - Удалить спринт

### Связи Задач
- `GET /api/task-links` - Получить список всех связей задач
- `POST /api/task-links` - Создать новую связь задач
- `DELETE /api/task-links/{id}` - Удалить связь задач

## Детали Реализации

### Конфигурация Базы Данных
Проект использует SQLAlchemy в качестве ORM с PostgreSQL в качестве бэкенда базы данных. Конфигурация базы данных управляется через переменные окружения в файле `.env`.

### Реализация API
REST API реализован с использованием фреймворка FastAPI, который предоставляет:
- Автоматическую документацию OpenAPI
- Валидацию запросов/ответов
- Поддержку асинхронности
- Подсказки типов

### Функции Управления Задачами
1. Создание и Управление Задачами
   - Создание задач с названием и описанием
   - Обновление статуса задачи
   - Удаление задач

2. Управление Спринтами
   - Создание и управление спринтами
   - Связывание задач со спринтами
   - Отслеживание прогресса спринта

3. Зависимости Задач
   - Связывание задач для отображения зависимостей
   - Управление отношениями между задачами
   - Отслеживание зависимостей задач

## Начало Работы

### Установка
1. Клонировать репозиторий
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настроить переменные окружения в файле `.env`
4. Запустить миграции:
   ```bash
   alembic upgrade head
   ```
5. Запустить сервер:
   ```bash
   uvicorn main:app --reload
   ```
